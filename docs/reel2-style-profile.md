## Style fingerprint (what to replicate)
- **Layout grammar:** Act 1 = strict **50/50 vertical split** (real top / AI bottom) with pill labels;
  Act 2 = **top-2/3 screen-content + bottom PiP presenter**. (Very different from reel 1's circle-PIP.)
- **Captions/labels:** NOT karaoke captions — **static white sans-bold text in black pills**
  ("Real Video", "Lip Sync …"); big white **display** font for the CTA.
- **B-roll:** AI-generated animated characters, lip-synced; tutorial uses clean dark-mode UI/motion
  graphics. Treatment is full-half (Act 1) or full top-2/3 (Act 2), not overlay-on-presenter.
- **Pacing:** fast — hard **cuts** every ~2–3s timed to dialogue; no fades/wipes (cut-only).
- **Logo:** persistent top-right.
- **Color grade:** clean studio for real footage; vibrant saturated for AI animation; dark-mode for
  the tutorial UI.
- **Sound design:** dialogue voiceover (Act 1) → presenter voiceover + ambient tech music (Act 2);
  bear roar SFX; UI click/pop SFX.
